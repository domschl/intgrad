Parameters and tensor shapes

Shapes use B = batch, T = context length, d = model width, H = heads, dh = d/H, f = 4d (MLP width). No biases. With the plain stem the output head reuses the embedding matrix (tied), so the 256 × d table is counted once; the conv stem has its own untied head. All convolutions are causal: position t sees bytes up to t only.

Magnitude control (decision 001-D9): pre-RMSNorm, QK-norm on queries and keys, z-loss 1e-4·lse² on the logits, optional soft-cap c·tanh(x/c) on the logits. Training: Lion, fp32 with TF32 in M3; byte numerics with per-tensor power-of-two scales in M4.
