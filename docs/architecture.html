Parameters and tensor shapes

Shapes use B = batch, T = byte context, d = model (patch) width, H = heads, dh = d/H, f = 4d (MLP width). Hourglass adds k = bytes per patch, db = byte width (d/2) and K = byte conv kernel (max(4, k)). No biases. The output head reuses the embedding matrix (tied), except with the conv stem. All convolutions are causal: position t sees bytes up to t only.

Hourglass causality: patch j covers bytes jk … jk+k−1, so its global vector exists only once byte jk+k−1 is read. The upsampled vectors are shifted right by k−1. Patch j then feeds the position that completes it and the k−1 positions inside patch j+1. Bytes already read inside the current patch reach the decoder through the byte skip and the causal convs. The tests check this at every offset, and removing the shift makes them fail.

Magnitude control (001-D9): pre-RMSNorm, QK-norm, z-loss 1e-4·lse². Training: Lion (lr 3e-3, wd 3, β 0.95/0.98; M5). M4 byte numerics: 16-bit master weights with a byte forward view; activations on the byte symlog grid at delayed power-of-two scales; attention scores and logits max-relative.
